# README - Recipes Project

## How to run the project

To start the application, follow the steps below:
1. Open **two terminals** – one for the frontend and one for the backend.
2. In each terminal, navigate to the corresponding directory.
3. Run `npm install` to install the dependencies.
4. Run `npm run dev` in both terminals to start the application.
5. In the frontend terminal, press `o` + `Enter` to open the application in the browser.
